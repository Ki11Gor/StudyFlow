---

## 📖 Опис проєкту

**StudyFlow** — навчальний вебзастосунок, призначений для студентів та учнів.

Основна мета проєкту — надати просте середовище, у якому користувач може зберігати навчальні предмети та завдання, контролювати дедлайни, встановлювати пріоритети й відстежувати виконання робіт.

StudyFlow розроблений як MVP у межах навчальної практики зі створення програмних продуктів.

---

## ✨ Основні можливості

### 👤 Для користувача

- реєстрація нового облікового запису;
- авторизація користувача;
- робота з персональними навчальними даними;
- збереження паролів у хешованому вигляді.

### 📚 Навчальні предмети

- створення предметів;
- перегляд списку предметів;
- редагування предметів;
- видалення предметів.

### ✅ Навчальні завдання

- створення навчальних завдань;
- додавання опису;
- прив'язка завдання до предмета;
- встановлення дедлайну;
- вибір пріоритету;
- використання статусів:
  - `Заплановано`;
  - `В процесі`;
  - `Виконано`;
- редагування завдань;
- видалення завдань;
- фільтрація за статусом.

### 📊 Статистика

StudyFlow дозволяє переглядати:

- загальну кількість завдань;
- кількість запланованих завдань;
- кількість завдань у процесі;
- кількість виконаних завдань;
- відсоток виконання.

### 📅 Найближчі завдання

На головній сторінці відображаються найближчі невиконані завдання, відсортовані за дедлайном.
